# Задача (аналитическая, теория вероятностей)

В ящике 5 монет:
- 2 монеты с орлом на обеих сторонах,
- 1 монета с решкой на обеих сторонах,
- 2 честные монеты.

Наугад берут одну монету и подбрасывают её **два раза**. Оба раза выпал орёл.

Какова вероятность того, что взятая монета — двуорловая?

## Эталонный ответ

P(HH | двуорловая) = 1, prior = 2/5 → 2/5
P(HH | честная)    = 1/4, prior = 2/5 → 1/10
P(HH | двурешёчная) = 0

P(HH) = 2/5 + 1/10 = 1/2
P(двуорловая | HH) = (2/5) / (1/2) = **4/5 = 0.8**

Типичные ошибки моделей: ответ 2/3 (учли один бросок), 1/2 (перепутали с P(HH)), 2/5 (проигнорировали условие).
