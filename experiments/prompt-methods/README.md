# Сравнение четырёх способов промптинга на одной задаче

Задача — в [task.md](task.md) (аналитическая, теория вероятностей, эталон = 4/5 = 0.8).

## Как запустить

Вариант A — через CLI (нужен вход: `claude` → `/login`):

    python3 run.py --backend cli --model claude-sonnet-5

Вариант B — через HTTP API (нужен ключ):

    export ANTHROPIC_API_KEY=sk-ant-...
    python3 run.py --backend api --model claude-sonnet-5

Скрипт делает 5 вызовов (способ 3 — два: генерация промпта + решение по нему)
и пишет `results.md` + `results.json`.

## Четыре способа

| # | Способ | Что в промпте |
|---|--------|----------------|
| 1 | Прямой ответ | только условие задачи |
| 2 | Chain-of-thought | «решай пошагово», явный порядок: гипотезы → приоры → правдоподобия → Байес |
| 3 | Мета-промпт | модель сама пишет промпт, затем решает по нему |
| 4 | Группа экспертов | аналитик + инженер + критик, затем согласованный ответ |

Модель по умолчанию — `claude-sonnet-5`. Для более наглядной разницы между
способами берите модель послабее (`claude-haiku-4-5-20251001`): сильная модель
часто решает верно даже способом 1, и сравнение вырождается.

## Как заполнять сравнение

После запуска — в [comparison.md](comparison.md): проставить ответ каждого способа,
верно/неверно, длину ответа и вывод.
