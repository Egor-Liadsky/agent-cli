## Why

Поля настроек TUI, которые принимают путь к каталогу для MCP-серверов
(корень проектов демона `activity-mcp`, репозиторий `git-mcp`), сейчас
заполняются только набором пути вручную. Длинный абсолютный путь легко
набрать с опечаткой, а ошибка всплывает лишь при запуске сервера. Нативный
диалог выбора папки (на macOS — Finder) снимает эту проблему, не отнимая
ручного ввода.

## What Changes

- В меню настроек TUI (`Ctrl+P`) у полей-каталогов появляется горячая
  клавиша `Ctrl+X`, открывающая системный диалог выбора папки через крейт
  `rfd` (`FileDialog::pick_folder`). Поля: «Корень проектов» раздела
  «Сводки активности» (`activity_root` конфига) и «Репозиторий» раздела
  инструментов (`git_repository` чата, аргумент `--repository` у `git-mcp`).
- Стартовый каталог диалога — текущее значение поля (с раскрытием `~`),
  если такой каталог существует, иначе домашний каталог.
- Выбранный путь записывается в поле редактора и сохраняется по `Ctrl+S`
  тем же путём, что и ручной ввод. Ручной ввод продолжает работать.
- На время диалога TUI освобождает терминал (raw-режим, альтернативный
  экран, захват мыши, bracketed paste) и затем полностью его
  восстанавливает.
- Если графической сессии нет (SSH, Linux без `DISPLAY`/`WAYLAND_DISPLAY`),
  диалог не открывается; при отмене или сбое `rfd` значение поля не
  меняется. Причина показывается в строке статуса.
- Новая зависимость `rfd` — только в `crates/cli`; README описывает
  клавишу и поведение без графической сессии.

Не меняется: поля `Config` ядра и формат `config.toml`, подкоманды
`agentcli config activity` / `config pipeline`. Каталоги `pipeline_root` и
`pipeline_output` в TUI не редактируются, поэтому диалога для них нет.

## Capabilities

### New Capabilities
- `settings-folder-picker`: выбор каталога для полей-путей в настройках TUI
  через нативный диалог ОС, с поведением при отмене и без графической
  сессии.

## Impact

- `crates/cli/Cargo.toml` — зависимость `rfd` без фич по умолчанию
  (`xdg-portal`), чтобы на Linux не требовались библиотеки GTK/Wayland при
  сборке.
- `crates/cli/src/folder_picker.rs` — новый модуль-обёртка над `rfd`.
- `crates/cli/src/tui.rs` — клавиша в `handle_settings_key`, запрос выбора
  в `AppState`, приостановка и восстановление терминала в `run_app`,
  подсказки.
- `README.md` — клавиша и поведение без графической сессии.
- `crates/core` не затрагивается.
