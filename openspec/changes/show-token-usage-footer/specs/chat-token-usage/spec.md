## Purpose

Показывает пользователю TUI-чата телеметрию расхода токенов — по последнему
обмену и накопительно по всему открытому чату, — используя только данные,
уже присланные сервером в ответе на запрос и в истории чата.

## ADDED Requirements

### Requirement: Строка телеметрии токенов внизу чата
Система SHALL показывать телеметрию токенов в отдельной строке статуса под
областью истории сообщений и над полем ввода, а не в шапке отдельного
сообщения.

#### Scenario: Есть телеметрия последнего обмена
- **WHEN** последнее сообщение ассистента в открытом чате содержит
  телеметрию токенов (`prompt_tokens`, `completion_tokens`,
  `reasoning_tokens` и/или `total_tokens`)
- **THEN** строка статуса внизу чата показывает отправленные, полученные,
  потраченные на рассуждение и итоговые токены этого обмена

#### Scenario: Телеметрии ещё нет
- **WHEN** в открытом чате ни одно сообщение не содержит телеметрии токенов
  (новый чат без ответов, либо провайдер её не прислал)
- **THEN** строка телеметрии токенов не выводится

### Requirement: Накопительный итог по чату
Система SHALL показывать сумму телеметрии токенов по всем сообщениям
открытого чата, у которых она присутствует, отдельно от телеметрии
последнего обмена.

#### Scenario: Несколько обменов с телеметрией
- **WHEN** в открытом чате несколько сообщений ассистента содержат
  телеметрию токенов
- **THEN** накопительный итог равен сумме соответствующих полей
  (`prompt_tokens`, `completion_tokens`, `reasoning_tokens`, `total_tokens`)
  по всем этим сообщениям

#### Scenario: Переключение между чатами
- **WHEN** пользователь переключается на другой открытый чат
- **THEN** и телеметрия последнего обмена, и накопительный итог
  пересчитываются по сообщениям вновь выбранного чата

### Requirement: Данные только от сервера
Система SHALL получать все числа телеметрии токенов из ответа сервера и
SHALL NOT вычислять их самостоятельно из текста запроса или ответа; клиенту
разрешается только суммировать уже присланные сервером целочисленные поля
телеметрии по сообщениям одного чата.

#### Scenario: Провайдер не прислал часть полей
- **WHEN** ответ сервера содержит только часть полей телеметрии (например,
  `prompt_tokens` и `completion_tokens`, но не `total_tokens`)
- **THEN** строка статуса показывает доступные поля и не пытается
  восстановить отсутствующее поле через анализ текста
