## Why

Сервер (`agent-sever`) уже присылает в каждом ответе `/v1/chat` и в истории
чата (`GET /v1/chats/{id}`) полную телеметрию по токенам — `prompt_tokens`,
`completion_tokens`, `reasoning_tokens`, `total_tokens` (`agent-sever/src/dto.rs`,
`UsageDto`). Ядро `agentcore` разбирает эти поля в `AgentReply::meta`
(`agent-cli/crates/core/src/agent/mod.rs`). В `crates/cli/src/tui.rs` уже
заготовлены функции для их отображения — `meta_token_summary`,
`chat_token_totals`, `token_counters`, `TokenTotals` (`tui.rs:2337-2415`) — но
ни одна из них нигде не вызывается: счётчики токенов в TUI сейчас не видны
пользователю вообще. Нужно довести эту недостающую часть до конца и вывести
телеметрию внизу окна чата, а не встраивать её в шапку каждого сообщения.

## What Changes

- Под областью истории чата, над полем ввода, добавляется постоянная строка
  статуса с телеметрией последнего обмена: отправлено (`prompt_tokens`),
  получено (`completion_tokens`), потрачено на рассуждение
  (`reasoning_tokens`), итог по обмену (`total_tokens`).
- Рядом (в той же строке или отдельным блоком статуса) отображается
  накопленный итог по всему открытому чату — сумма телеметрии всех
  сообщений с `meta`, уже присланной сервером в истории чата.
- Существующие функции `meta_token_summary`, `chat_token_totals`,
  `token_counters`, `TokenTotals` вызываются из `render_input` (или соседней
  новой функции рендера строки статуса); дублирующий вывод токенов в шапке
  сообщения (`meta_summary`) не добавляется — токены остаются только внизу.
- Если для чата ещё нет ни одного сообщения с телеметрией (например, только
  что созданный чат или провайдер её не прислал), строка статуса токенов не
  выводится — без вводящих в заблуждение нулей.
- Клиент не вычисляет токены из текста и не обращается к отдельному API за
  статистикой — только показывает и суммирует уже присланные сервером целые
  числа per-message.

## Capabilities

### New Capabilities

- `chat-token-usage`: отображение в TUI телеметрии токенов последнего обмена
  и накопительного итога по чату на основе данных, присланных сервером.

### Modified Capabilities

(нет — существующие спеки в `openspec/specs` отсутствуют, это первая спека
для TUI-чата)

## Impact

- `agent-cli/crates/cli/src/tui.rs`: `render_input` (или новая функция
  рядом), вызов уже существующих `meta_token_summary`/`chat_token_totals`.
- Изменений в `agent-cli/crates/core` и в `agent-sever` не требуется — данные
  уже присылаются сервером в текущем формате ответа.
