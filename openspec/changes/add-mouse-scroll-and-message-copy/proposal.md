## Why

Историю чата в TUI сейчас можно листать только с клавиатуры: `↑`/`↓` и
`PageUp`/`PageDown` в `handle_input_key` (`crates/cli/src/tui.rs:3110-3132`).
Колесо мыши не работает, потому что захват мыши намеренно не включён
(`crates/cli/src/tui.rs:1537-1542`): комментарий в коде объясняет, что
`EnableMouseCapture` отключил бы нативное выделение текста терминалом, а
другого способа скопировать ответ модели у пользователя нет — `Ctrl+Y`
копирует только поле ввода (`crates/cli/src/tui.rs:1892-1903`).

Компромисс устарел: листать длинные ответы клавишами неудобно, а
терминалы (iTerm2, Terminal.app, GNOME Terminal, kitty, Alacritty, Windows
Terminal) отдают нативное выделение по `Shift`+перетаскиванию даже при
включённом захвате мыши. Если одновременно добавить копирование сообщения
целиком из самого TUI, потеря обычного выделения перестаёт быть блокирующей.

## What Changes

- Включается захват мыши (`EnableMouseCapture` при входе в альтернативный
  экран, `DisableMouseCapture` при выходе), в цикле событий обрабатываются
  `Event::Mouse` с `MouseEventKind::ScrollUp`/`ScrollDown`.
- Колесо прокручивает историю той панели, над которой находится курсор, а не
  активной панели: при нескольких открытых чатах прокручивается то, на что
  пользователь смотрит. Колесо вне области истории (боковая панель, поле
  ввода, подсказка, открытое модальное окно) историю не трогает.
- Прокрутка колесом выключает автопрокрутку к низу и включает её обратно при
  достижении низа — так же, как постраничные клавиши.
- Построчная прокрутка стрелками `↑`/`↓` из поля ввода убирается: этот шаг
  переходит на колесо, а `PageUp`/`PageDown` остаются.
- Добавляется режим выбора сообщения в истории: горячая клавиша открывает
  его, `↑`/`↓` переходят между сообщениями чата, выбранное подсвечивается и
  подтягивается в видимую область, отдельная клавиша копирует **текст**
  выбранного сообщения в системный буфер обмена через существующий
  `crate::clipboard::copy` (`arboard`, с откатом на OSC 52). Заголовок
  («● Агент») и метрики токенов в буфер не попадают.
- `Esc` закрывает режим выбора и возвращает фокус в поле ввода; прочие
  экраны (`Ctrl+P`, `Ctrl+F`, `Ctrl+B`, `Ctrl+K`, `Ctrl+T`, `Ctrl+O`)
  перехватывают клавиши раньше, поэтому режим выбора с ними не конфликтует.
- README дополняется: колесо мыши в истории, `Shift`+перетаскивание для
  нативного выделения при включённом захвате, клавиши режима выбора и
  копирования сообщения.

## Capabilities

### New Capabilities

- `chat-history-navigation`: прокрутка истории чата в TUI (клавиатура и
  колесо мыши) и копирование текста отдельного сообщения в системный буфер
  обмена, включая сохранение доступа к нативному выделению терминала.

### Modified Capabilities

(нет — в `openspec/specs/` пока нет спек, затрагивающих навигацию по истории)

## Impact

- `crates/cli/src/tui.rs`: инициализация терминала (`run`), цикл событий
  (`run_app`), `handle_input_key`, `render_history`, `render_help`,
  структура `ChatUi` (состояние выбранного сообщения), `render_pane` и
  `render_ui` — сохранение прямоугольников панелей для попадания курсора.
- `crates/cli/src/clipboard.rs` — используется как есть, без изменений.
- `crates/core` и репозиторий `agent-sever` не затрагиваются: изменение
  целиком клиентское, сетевых запросов не добавляет.
- README `agent-cli` (раздел про горячие клавиши).
