## Purpose

Определяет раздел «Пайплайн» в меню настроек TUI: как пользователь видит,
правит, очищает и сохраняет каталоги MCP-сервера `pipeline-mcp` — каталог
поиска и каталог записи — не выходя из чата.

## ADDED Requirements

### Requirement: Раздел отражает конфиг клиента
Система SHALL показывать в меню настроек (`Ctrl+P`) раздел «Пайплайн» сразу
после раздела «Сводки активности» с полями «Каталог поиска» и «Каталог
записи», заполненными из `pipeline_root` и `pipeline_output` конфига
клиента. Значения SHALL быть общими для всех чатов и SHALL не входить в
параметры чата, которые отправляются сервису.

#### Scenario: Каталоги заданы
- **WHEN** в конфиге `pipeline_root = "~/projects/ai"` и
  `pipeline_output = "~/out"`, и пользователь открывает раздел «Пайплайн»
- **THEN** поле «Каталог поиска» содержит `~/projects/ai`, а «Каталог
  записи» — `~/out`

#### Scenario: Каталоги не заданы
- **WHEN** в конфиге нет ни `pipeline_root`, ни `pipeline_output`
- **THEN** оба поля пусты, а на месте значения «Каталог поиска» видна
  подсказка, что инструменты пайплайна выключены

### Requirement: Эффективный каталог записи в подсказке
Система SHALL показывать на месте пустого поля «Каталог записи» путь, куда
будет писать пайплайн: `<каталог поиска>/pipeline-out` по текущему значению
поля «Каталог поиска». Если каталог поиска тоже пуст, подсказка SHALL
сообщать, что сначала нужен каталог поиска.

#### Scenario: Задан только каталог поиска
- **WHEN** поле «Каталог поиска» содержит `/work`, а «Каталог записи» пусто
- **THEN** на месте значения «Каталог записи» видно `/work/pipeline-out`

### Requirement: Правка и очистка полей
Система SHALL принимать ввод с клавиатуры в оба поля, SHALL открывать по
`Ctrl+X` системный диалог выбора папки на любом из них и записывать
выбранный путь в это поле, и SHALL очищать выделенное поле по `Ctrl+D`.
Отмена или недоступность диалога SHALL оставлять поле без изменений.

#### Scenario: Выбор каталога записи диалогом
- **WHEN** выделено поле «Каталог записи», пользователь нажимает `Ctrl+X`
  и выбирает папку `/Users/me/out`
- **THEN** поле «Каталог записи» содержит `/Users/me/out`, а поле
  «Каталог поиска» не изменилось

#### Scenario: Очистка поля
- **WHEN** выделено непустое поле «Каталог поиска» и пользователь нажимает
  `Ctrl+D`
- **THEN** поле пусто

### Requirement: Сохранение по Ctrl+S
Система SHALL по `Ctrl+S` записывать оба поля в конфиг клиента; пустое или
состоящее из пробелов поле SHALL записываться как отсутствующее значение, а
не пустая строка. Если значения совпадают с конфигом, система SHALL не
переписывать файл конфига. Следующий ход любого чата после сохранения SHALL
использовать новые каталоги: пустой каталог поиска выключает инструменты
пайплайна, заданный — включает.

#### Scenario: Включение пайплайна из TUI
- **WHEN** пользователь вводит `~/projects/ai` в «Каталог поиска», оставляет
  «Каталог записи» пустым и нажимает `Ctrl+S`
- **THEN** в конфиге `pipeline_root = "~/projects/ai"`, `pipeline_output`
  отсутствует, `agentcli config pipeline show` показывает этот каталог, а
  следующий ход чата получает инструменты `search`, `summarize`,
  `save_to_file`

#### Scenario: Выключение пайплайна из TUI
- **WHEN** пользователь очищает «Каталог поиска» и нажимает `Ctrl+S`
- **THEN** `pipeline_root` в конфиге отсутствует, и следующий ход чата идёт
  без инструментов пайплайна

#### Scenario: Значения не менялись
- **WHEN** пользователь открывает настройки и нажимает `Ctrl+S`, не трогая
  поля раздела
- **THEN** конфиг из-за раздела «Пайплайн» не переписывается
